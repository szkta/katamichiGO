# トヨタレンタカー空車監視Bot (GAS版)
トヨタレンタカーのWebサイト（片道GO!などのキャンペーンページ）を定期的に監視し、新しい車両が登録されたり、受付が終了した際に Discord へ通知を送る Google Apps Script (GAS) です。
地域ごとのチャンネル振り分けや、特定のレア車種（GR86, アルファード等）の別通知に対応しています。
# ✨ 機能
 * 自動監視: 指定したURLを定期的にチェックし、車両の増減を検知します。
 * Discord通知:
   * 新着 (🟢): 新しくリストに追加された車両を通知。
   * 受付終了 (🔴): リストから消えた、または受付終了になった車両を通知。
   * レア車検知 (💎): 指定したキーワード（車種名）にヒットした場合、特別なアイコンで通知し、専用チャンネルへ振り分けが可能。
 * エリア別通知: 「関東」「東北」など、出発エリアごとに通知先のDiscordチャンネルを変えることができます。
 * 誤検知防止:
   * 車種名に含まれる「車両番号xxxx」などの動的な数値を自動除去し、車種名だけで正しくレア判定を行います。
   * 全角・半角（ＧＲ８６ ⇔ GR86）の表記ゆれを自動吸収して判定します。
 * スマホ最適化: 通知内の電話番号はタップですぐ発信できる形式で表示されます。
# 🛠 導入方法
1. Google Apps Script プロジェクトの作成
 * Google Apps Script にアクセスし、「新しいプロジェクト」を作成します。
 * エディタに code.gs の内容をすべてコピペします。
2. Discord Webhookの取得
通知を送りたいDiscordチャンネルごとに、以下の手順でWebhook URLを取得してください。
 * Discordチャンネルの「設定（歯車マーク）」を開く。
 * 「連携サービス」→「ウェブフック」→「新しいウェブフック」を作成。
 * 「ウェブフックURLをコピー」をクリック。
3. スクリプトの設定
コード冒頭の AREA_CONFIG と RARE_CAR_CONFIG を編集します。
エリア設定 (AREA_CONFIG)
監視したいエリアのIDと、通知先のWebhook URLを設定します。

```JavaScript
const AREA_CONFIG = [
  { 
    name: '関東', 
    id: '3', // サイト上のdata-area-id (関東=3, 東北=2など)
    webhook: 'https://discord.com/api/webhooks/xxxx/xxxx' 
  },
  // ...他のエリア
];
```

レア車設定 (RARE_CAR_CONFIG)
特定の車種を別チャンネルに飛ばしたい場合に設定します。
```JavaScript
const RARE_CAR_CONFIG = {
  // 監視したいキーワード（半角・全角どちらでもOK）
  keywords: ['ハリアー', 'アルファード', '86', 'GR86', 'クラウン'],
  
  // レア車専用の通知先URL
  webhook: 'https://discord.com/api/webhooks/yyyy/yyyy',
  
  // 通常チャンネルにも重複して送るか (true/false)
  sendToNormalChannelAlso: false 
};
```
4. トリガーの設定（自動実行）
スクリプトを定期的に動かすために「トリガー」を設定します。
 * GAS画面左側の「トリガー（時計アイコン）」をクリック。
 * 右下の「トリガーを追加」ボタンをクリック。
 * 以下のように設定して保存します。
   * 実行する関数: checkNewCars
   * イベントのソース: 時間主導型
   * タイプ: 分ベースのタイマー
   * 間隔: 10分おき（※サイト負荷を考慮し、短すぎない時間を推奨）
# ⚠️ 注意事項・免責
 * サイトへの負荷: クローリング（スクレイピング）を行う際は、相手方サーバーへの負荷を考慮し、実行頻度を上げすぎないようにしてください（推奨：10分〜30分間隔）。
 * 仕様変更: 対象サイトのHTML構造（クラス名など）が変更された場合、このスクリプトは動作しなくなります。その際は正規表現部分の修正が必要です。
