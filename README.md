# トヨタレンタカー空車監視Bot (GAS版)

トヨタレンタカーの「片道GO!」等のキャンペーンページを定期的に監視し、車両の空き状況（新着・受付終了）を **Discord** へ通知する Google Apps Script (GAS) です。

地域ごとのチャンネル振り分け、特定車種（レア車）の専用通知、返却店舗に応じたリンク自動添付など、高度なカスタマイズが可能です。

## ✨ 主な機能

1. **自動監視 & 通知**:
* 指定したURLを定期チェックし、車両の増減を検知。
* **🟢 新着**: 新しく追加された車両を通知。
* **🔴 終了**: 受付が終了した（リストから消えた）車両を通知。
* 通知には「車種」「出発/返却店舗」「期間」「電話番号」「現在時刻」が含まれます。


2. **エリア別チャンネル振り分け**:
* 「関東」「東北」「中部」など、出発エリアごとに異なるDiscordチャンネル（Webhook）へ通知を振り分け可能。


3. **レア車検知システム**:
* 指定したキーワード（例: `GR86`, `アルファード`）が含まれる車種を「💎 **激レア車両**」として検知。
* 通常とは別の「レア車専用チャンネル」に通知を送ることができます。
* 全角・半角の表記ゆれ（`ＧＲ８６` ⇔ `GR86`）を自動吸収。
* 車両番号（例: `車両番号9863`）による誤判定（`86`と誤認など）を防ぐクリーニング機能付き。


4. **返却店舗リンク機能**:
* 返却先の店舗名（例: "静岡"）に応じて、設定したURL（店舗一覧や地図など）を自動でメッセージに添付。
* 1つの店舗に対して複数のリンク（例: `[店舗一覧]` `[地図]`）を設定可能。


5. **スマホ最適化**:
* 電話番号はスマホでタップして発信しやすい形式で表示（ハイフン維持）。



## 🛠 導入手順

### 1. Google Apps Script プロジェクトの作成

1. [Google Apps Script](https://script.google.com/) にアクセスし、「新しいプロジェクト」を作成。
2. エディタにスクリプト（`code.gs`）の内容をすべてコピペして保存します。

### 2. Discord Webhookの取得

通知を送りたいDiscordチャンネルごとに Webhook URL を発行してください。

* *（チャンネル設定 ＞ 連携サービス ＞ ウェブフック ＞ 新しいウェブフック）*

### 3. コード内の設定変更

スクリプト冒頭にある以下の3つの設定セクションを書き換えます。

#### ① エリア設定 (`AREA_CONFIG`)

監視したいエリアIDと通知先を設定します。

```javascript
const AREA_CONFIG = [
  { 
    name: '関東', 
    id: '3', // サイト上のエリアID (例: 関東=3, 東北=2)
    webhook: 'https://discord.com/api/webhooks/xxxx/xxxx' // 関東用通知URL
  },
  // 必要な分だけ追加...
];

```

#### ② 返却店舗リンク設定 (`RETURN_SHOP_URLS`)

返却店舗名に含まれるキーワードと、表示させたいリンクを設定します。

```javascript
const RETURN_SHOP_URLS = {
  '静岡': [
    { label: '店舗一覧', url: 'https://www.r-shizuoka.co.jp/shops/' },
    { label: '地図', url: 'https://goo.gl/maps/xxxx' }
  ],
  '愛知': [
    { label: '店舗一覧', url: 'https://www.trl-aichi.co.jp/shop/' }
  ]
};

```

#### ③ レア車設定 (`RARE_CAR_CONFIG`)

特別扱いしたい車種キーワードを設定します。

```javascript
const RARE_CAR_CONFIG = {
  // 監視キーワード（半角で入力すれば全角もヒットします）
  keywords: ['ハリアー', 'アルファード', 'GR86', 'クラウン'],
  
  // レア車専用の通知先URL
  webhook: 'https://discord.com/api/webhooks/yyyy/yyyy',
  
  // 通常のエリアチャンネルにも重複して送るか (true/false)
  sendToNormalChannelAlso: false 
};

```

### 4. トリガーの設定（自動実行）

スクリプトが定期的に動くように設定します。

1. GAS画面左メニューの「トリガー（時計アイコン）」を選択。
2. 右下の「トリガーを追加」ボタンを押す。
3. 設定内容:
* 実行する関数: `checkNewCars`
* イベントのソース: `時間主導型`
* タイプ: `分ベースのタイマー`
* 間隔: `10分おき`（推奨）



## ⚠️ 注意事項

* **動作環境**: トヨタレンタカー公式サイトのHTML構造に依存しています。サイトのデザイン変更（リニューアル）があった場合、動作しなくなる可能性があります。
* **アクセス頻度**: 相手サーバーへの負荷を考慮し、実行間隔は短すぎないよう（10分以上推奨）設定してください。
